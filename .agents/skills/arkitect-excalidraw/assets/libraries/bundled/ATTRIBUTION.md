# Bundled libraries — credits

36 Excalidraw libraries, 1162 items, all of them
native vector geometry — no embedded images anywhere in the set.

They come from the public catalogue at libraries.excalidraw.com and belong to
their authors, who are credited below. They are committed here so a diagram can
be drawn offline and so the same mark is used for the same product every time.
Each remains under whatever licence its author published it under; follow the
catalogue link before reusing one outside a diagram.

Rebuild this file and the index with `node scripts/index-libraries.mjs --build`.
Credits live in `authors.json`, matched against the catalogue on 2026-09-08.
